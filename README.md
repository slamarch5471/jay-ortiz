# Jay Ortiz – Business Broker Website

A website project for Jay Ortiz, a business broker serving the Southwest Florida area.

## Overview

The site introduces the business broker and provides information about services, client reviews, and ways to request a consultation.

## Built with

- HTML
- CSS

## Main sections

- About
- Services
- Reviews
- Contact and consultation information

## Project purpose

This project demonstrates front-end website development for a professional services business, including page structure, navigation, responsive layout, and visual styling.
